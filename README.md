# Masters-application-diy-guide
# 西浦（XJTLU）硕士申研 DIY 攻略

## 前言

不同地区与学校的审核标准和偏好各异，本攻略专门针对西浦（XJTLU）学生的背景与优势制定。

---

## 1. 提前准备清单

* **简历 (CV)：** 简明扼要，突出量化成果与技术栈。
* **个人陈述 (PS) 主干：** 梳理核心逻辑线，便于后续针对不同学校微调。
* **SOP (Statement of Purpose)：** 部分美校/加校硬性要求，比 PS 更偏重学术与职业规划。
* **语言成绩：** 西浦学生申请英国、澳洲及部分香港、新加坡项目通常免语言；美加或部分特定项目仍需托福、雅思或 GRE，需提前确认。
* **推荐信 (RL)：** 提早规划，建议储备 4 至 5 位潜在推荐人。

---

## 2. 申请时间线

### 大三下学期（3月 - 6月）
* 保持并提升 GPA（大三成绩权重极大）。
* 确定推荐人人选，积极参与 SURF、FYP 课题或实习。

### 大三暑假（7月 - 8月）
* 梳理经历，撰写 CV 与 PS 初稿。
* 整理选校 List，查询各校开放申请时间与 Deadline。

### 大四上学期（9月 - 12月）
* 开学第一时间联系老师锁定推荐信。
* 开放网申后分批次提交，跟进推荐信完成状态。

### 大四下学期（1月 - 4月）
* 陆续接收 Offer，注意留位费截止日期，做好梯度选择。

---

## 3. 选校策略与信息获取

### 信息收集渠道
* **资讯与社群：** 关注留学公众号、小红书、纸条留学圈，寻找往届背景相似（GPA/专业）的西浦学长学姐取经。
* **CS/理工科申请难度查询：** 一亩三分地、GradCafe、小红书。

### 选校心态与保底原则
* **广撒网与多国混申：** 各校录取标准每年均有波动，冲刺校多往上尝试，保底校也要选得有技巧。
* **保底校选择标准：** 出结果早、留位费政策友好（截止日期晚、金额合理）。

### CS 相关专业梯度及保底参考（针对西浦背景）

| 学校/项目 | 选校特点与西浦匹配度 |
| :--- | :--- |
| **爱丁堡大学 (CS / AI)** | 对西浦免语言。第一批能录取体验较好；但有时会审查至 5 月。成绩稍低可尝试 HPC（高性能计算）或认知科学。 |
| **曼彻斯特大学 (ACS)** | 无留位费，录取门槛比爱丁堡 CS/AI 略低，极其看重大三成绩。 |
| **南加州大学 (USC CS)** | 录取门槛相对友好，正统 CS 大厂认可度高，留位费及截止日期较合理。 |
| **南洋理工大学 (NTU SPML)** | 学术门槛友好，但留位费政策一般，且录取发放周期较长（可能持续至 6 月）。 |

## 4. 推荐信（RL）准备

* **储备数量：** 大多数学校需要 2 至 3 封，强烈建议准备 4 至 5 位推荐人备用。
* **获取途径：** 科研导师、实习 Leader、FYP 导师、高分授课老师。（西浦学生快速获取科研推荐信途径：SURF 项目）。
* **提前沟通：** 了解推荐人的推荐强度及可提交的数量上限。
* **观察提交风格：**
  * 部分老师习惯等所有学校链接到齐后一次性提交；部分习惯来一封交一封；部分限制学校数量；部分会拖延甚至出现不回复的情况。
  * **应对策略：** 网申开启后，先给每个推荐人发送 1 至 2 个学校进行测试，观察其处理速度和习惯，再合理分配后续学校。
  * **注意事项：** 在保证推荐强度的前提下，西浦外教的推荐信通常具有较高的认可度。

## 5. 文书（PS/SOP）撰写指南

### 工具与润色
* **合理使用 AI：** 可用于逻辑结构头脑风暴与句式重组，但项目细节与核心思考必须自己提供，避免产生虚假细节。
* **母语润色：** 建议找英语母语者进行语言润色（利物浦大学官方提供免费的 Writing Center 语言支持服务，可用于润色语法）。
* **同行评审：** 找可靠的同学或学长学姐帮忙检查逻辑，避免陷入主观偏差。

### PS 八段式结构

1. **第一段 (Hook)：** 引入核心主线。避免使用“我从小就对计算机感兴趣”等无实际信息的表达。建议使用科研或实习中的独特感悟、特殊经历作为切入点。
2. **第二至五段 (Core Experiences)：** 挑选 3 至 4 段有含金量且与申请专业强相关的经历（科研/实习/大创/FYP）。
   * 遵循 **STAR 原则**（Situation, Task, Action, Result）。
   * **与 CV 的区别：** CV 注重简洁与量化结果；PS 展示过程、遇到的问题、解决思路与事后思考。适当展现过程的曲折性有助于提升故事性与真实感。
3. **第六段 (Why School)：** 契合度说明。可分析课程匹配度，也可结合具体教授的研究方向。
4. **第七段 (Community Contribution)：** 说明能为该项目或校园社区带来的价值与贡献。
5. **第八段 (Conclusion)：** 总结主线，呼应开头，阐明短期与长期的职业或学术规划。

---

## 6. 网申实用技巧与心态建设

### 实操技巧
* **建立个人信息 Master Word：** 将 Address, Passport No., GPA, Course List, Extracurriculars 等频繁填写的文本集中整理，便于复制粘贴。
* **进度追踪表：** 使用 Excel 或 Notion 建立进度看板，标注每个项目名称、账号密码、Deadline、推荐信提交状态、留位费 Deadline 及金额。

### 心态建设
* DIY 没有中介兜底，出现焦虑属于正常现象。
* **应对策略：** 做好梯队规划（冲刺/稳妥/保底）、多国混申、尽早投递。
* **专注自身：** 减少无意义的背景对比，专注完成每一个申请步骤。
